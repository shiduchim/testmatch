# testmatch

Design lab for the next shidduch assistant / personal CRM.

This repository intentionally contains multiple interface experiments side by side. They use synthetic demo data only and are meant to compare information architecture before committing to a final build.

Experiments:

1. Ledger — bank-app-style activity history
2. Case File — person-first record with tabs and connections
3. Today — action-first home screen for daily shidduch work
4. PeerMatch+ — closest to the proven compact PeerMatch workflow, with a cleaner activity ledger

Open `index.html` through GitHub Pages to compare them.
